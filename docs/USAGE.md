## 1. 项目介绍及核心功能

Syncra 是一个 **Android 悬浮翻译器**。它不在后台偷偷读你的东西，而是在你主动打开时，通过 Android 的「无障碍服务」读取当前屏幕上的文字，翻译后**把译文直接覆盖在原文位置上**。

### 主要功能

| 功能 | 说明 |
|---|---|
| **读屏翻译** | 读取当前屏幕上的消息文字，把译文画在原文位置。适合 X（推特）私聊、Telegram、浏览器等 |
| **输入框翻译** | 读取你正在输入的内容，翻成目标语言后写回输入框 |
| **自动模式** | 自动识别屏幕内容、跟随滚动，有新消息或新输入时自动翻译 |
| **目标语言锁定** | 在悬浮球面板里固定翻译目标语言，不依赖自动识别 |
| **本地缓存** | 翻译过的句子存在手机上，同一句不重复请求 |
| **多语言界面** | 中文 / English / 日本語 / 한국어 |
| **深色模式** | 跟随系统 |

### 技术特点

- 不内置任何离线翻译模型，安装包约 3 MB；
- 走 OpenRouter 的云端 API，**API Key 由用户自己填**，代码里绝不内置；
- 支持任意语言，不限定语种。

## 2. APK 下载与安装

### 下载

1. 打开 https://github.com/guluguluhuhu/syncra/releases
2. 找到最新的 Release（目前是 **v1.1**）
3. 在 **Assets** 里点 **`Syncra.apk`** 下载

### 安装

1. 用手机打开下载好的 APK；
2. 系统可能提示「未知来源应用」，需要允许你的浏览器/文件管理器「安装未知应用」；
3. 点击安装。

### 系统要求

- **Android 10（API 29）及以上**；
- 不支持 iOS，也不是网页版。

### 版本说明

- 当前最新版本：**v1.1**（versionCode 2）；
- 如果你从更早的版本升级，包名和签名没变，可以直接覆盖安装；
- 如果之前装过开发版（`com.vipin25.bubbletranslate`），那是另一个应用，需要卸载后重新安装。

## 3. OpenRouter 账号及 API Key 配置

Syncra 本身不提供翻译能力，它调用 **OpenRouter** 的接口。

### 注册

1. 浏览器打开 https://openrouter.ai
2. 用 Google / GitHub 账号登录（或邮箱注册）
3. 进入 **Keys** 页面（https://openrouter.ai/keys）
4. 点 **Create Key**，起个名字（比如 `syncra`）
5. 复制生成的 Key（形如 `sk-or-v1-...`），**只显示一次，记得保存**

### 填进 Syncra

1. 打开 Syncra 主界面；
2. 在 **API Key** 输入框粘贴刚才复制的 Key（输入框右侧有眼睛图标，可以切换显示/隐藏）；
3. 点 **「保存设置」**；
4. 底部会提示「已保存」，说明写入成功。

> ⚠️ Key 只保存在手机本地，不会上传到任何地方。

### 免费能用吗？

可以。默认模型是 `openrouter/free`，会路由到免费的模型。但免费模型**经常限流**，表现是翻译失败、卡住或很慢。日常使用建议换付费模型（见下一节）。

## 4. 模型选择与配置建议

主界面有 **「模型」** 选项，点开是模型列表（列表来自 OpenRouter 的公开模型接口，不需要 Key 就能拉取）。

### 默认与推荐

| 模型 | 特点 | 建议 |
|---|---|---|
| `openrouter/free` | 免费，自动路由到免费模型 | 试水可以，长期用不稳定 |
| `deepseek/deepseek-chat` | 便宜（一句话的 token 成本接近于零）、多语言好 | **推荐日常使用** |
| 其他付费模型 | 质量更好、更贵 | 按需选择 |

### 怎么换

1. 主界面点 **「模型」**；
2. 在列表里选一个；
3. 点 **「保存设置」**。

### 还有「允许付费模型」开关

- 关：只用免费模型；
- 开：列表里出现付费模型，可以选。

> 作者原话：**「如果翻译卡住或者报错，优先使用付费的模型（DeepSeek 之类的很便宜，一句话的 token 翻译付费接近于零）。」**

## 5. Android 悬浮窗权限设置

悬浮球需要「显示在其他应用上层」权限。

### 什么时候会要

第一次点 **「启动悬浮球」** 时，如果没授权，会跳到系统设置页。

### 怎么开

不同品牌路径不同（以下为常见路径，可能因系统版本略有差异）：

- **原生 Android / 类原生**：设置 → 应用 → 特殊应用权限 → 显示在其他应用上层 → Syncra
- **小米 / Redmi**：设置 → 应用设置 → 应用管理 → Syncra → 权限管理 → 显示悬浮窗
- **华为 / 荣耀**：设置 → 应用 → 应用管理 → Syncra → 权限 → 悬浮窗
- **OPPO / 一加 / realme**：设置 → 应用 → 应用管理 → Syncra → 权限 → 悬浮窗
- **vivo / iQOO**：设置 → 应用与权限 → 权限管理 → 悬浮窗 → Syncra

### 找不到怎么办

在设置顶部的**搜索框**直接搜 `Syncra`，进去后找「权限」→「悬浮窗 / 显示在其他应用上层」。

> ⚠️ 这个权限是**按包名**记录的。如果以后换了包名（重装成另一个包名），需要重新授权。

## 6. 无障碍服务权限设置

这是 Syncra 的核心权限，**不开就无法读屏和写输入框**。

### 怎么开

1. 打开 Syncra 主界面；
2. 点 **「打开无障碍设置」**（或根据界面提示跳转）；
3. 在系统列表里找到 **Syncra**；
4. 打开开关，确认弹窗里的提示；
5. 回到 Syncra，界面会显示「无障碍已开启」。

### 不同品牌路径

- 设置 → 无障碍 → 已下载的服务 / 已安装的服务 → Syncra
- 小米：设置 → 更多设置 → 无障碍 → 已下载的应用 → Syncra
- 华为：设置 → 辅助功能 → 无障碍 → 已安装的服务 → Syncra

### 重要：什么时候需要重新开

以下情况 Android 会**自动禁用**无障碍服务，需要你手动重新打开：

- 从最近任务里**划掉**了 Syncra（force-stop）；
- 卸载重装、改包名；
- 部分系统升级后。

> 作者原话：**「软件需要常驻后台，一旦清理下次使用需要重新打开无障碍模式。建议锁定。」**
>
> 「锁定」指在最近任务里长按 Syncra 卡片 → 加锁 / 锁定，避免被系统清理。

## 7. 悬浮球的启动与基本操作

### 启动

主界面点 **「启动悬浮球」**。成功后屏幕上出现一个二次元角色（DeepSeek 鲸鱼娘）。

### 基本操作

| 操作 | 效果 |
|---|---|
| **单击** | 打开/收起设置小面板 |
| **长按** | 清掉当前屏幕上的译文层 |
| **拖动** | 移动位置；松手后会吸附到最近的屏幕边缘 |
| **吸附状态** | 只露出半个头（`mascot_peek`），不挡内容；再点一下恢复全身 |

### 设置面板里有什么

点悬浮球打开面板后，从上到下：

1. **自动翻译** 开关（开 / 关，显示「开 · 实时跟随」或「关 · 休眠」）
2. **「立即翻译一次」** 按钮：手动读屏翻译一次（同时也会尝试翻输入框）
3. **「目标语言」** 下拉：自动 / English / 日本語 / 한국어 / Русский / العربية / 中文
4. **「翻译输入框」** 按钮：只翻输入框，目标语言用上面锁定的那个
5. **「关闭」** 按钮：收起面板

### 目标语言怎么理解

- 选 **「自动」**：按「锁定的语言不存在 → 屏幕上对方用的语言 → 英文」的顺序判断；
- 选 **某个语言**：之后选中翻译和「翻译输入框」都固定用它。

### 悬浮球大小

主界面底部有 **「悬浮球大小」**：小 / 中 / 大，选完立即生效，并会记住。

## 8. 屏幕阅读翻译的使用方法

这是 Syncra 最核心的功能，适合「对方发的消息是外语，长按又选不中文字」的场景（比如 X 私聊）。

### 手动翻一次

1. 打开对方发消息的界面；
2. 点一下悬浮球 → 面板 → **「立即翻译一次」**；
3. 屏幕上会出现浅灰底的译文卡片，**贴在每段原文的位置上**；
4. 点悬浮球 →「关闭」或长按悬浮球可以清掉译文。

### 自动跟随

1. 面板里把 **「自动翻译」** 打开；
2. 之后你滚动、切换页面，它会自动重新扫描并翻译；
3. 译文会跟着滚动位置更新。

### 译文层的显示规则（源码证实）

- 译文框底部限制在屏幕 **82%** 以内（键盘弹起时），避免挡输入框；
- 键盘收起后放宽到 **96%**，显示完整内容；
- 原文太靠下时，译文框会整体上提；
- 文字过多时会在输入框上沿截断。

## 9. 输入框翻译的使用方法

### 方式一：自动（推荐先试）

1. 打开 **「自动翻译」**；
2. 在输入框里打中文；
3. 停 **约 2~3 秒**（有防抖延迟，正常现象）；
4. 它会把中文翻成目标语言并写回输入框；
5. 继续输入，只翻新增的句子，前面的译文保留（阶段式拼接）。

### 方式二：手动整段翻译（推荐大段文字）

1. 在输入框里打完内容（可以先关掉自动翻译，避免它中途触发）；
2. 点悬浮球 → 面板 → **「翻译输入框」**；
3. 它会把这**一整段**一次性翻译，不按句子切，保证连贯；
4. 结果直接写回输入框，你检查后发送。

### 两种方式的区别（源码证实）

| 方式 | 翻译粒度 | 适合 |
|---|---|---|
| 自动 | 按句子切，增量拼接 | 边打边看、短句 |
| **「翻译输入框」按钮** | 整段一次翻 | 大段、长句、发送前精修 |

### 输入框翻译的已知行为（源码证实）

- 如果输入框里已经有上一次的译文（比如日文），再输入中文时，**只处理新增的中文部分**，已有译文不重翻；
- 写回前会检查内容有没有变化，变过就放弃这次写回，避免吞掉你新打的字；
- 写回后光标会移到末尾。

## 10. 自动翻译模式的使用方法

### 它同时控制三件事

1. **自动读屏翻译**（对方消息）
2. **自动跟随滚动**（页面变化时重新翻译）
3. **自动输入框翻译**（打字后自动翻）

关闭后全部休眠，只响应手动点击。

### 开启

面板里打开 **「自动翻译」** 即可。主界面也有一个开关，效果相同。

### 关闭

面板里关掉，或主界面关掉。关闭时：

- 覆盖层立即清除；
- 正在跑的翻译任务会被取消（不会「关了又自己冒出来」）。

### 防抖

输入框翻译有 **约 2 秒**的防抖延迟，读屏翻译有 **3 秒**停顿判定。这是正常设计，不是卡住。

> 作者原话：**「翻译会有两秒的防抖延迟，是正常的。」**

## 11. 常见问题与故障排查

### Q1：翻译一直转圈 / 一直「翻译中」

1. 先看是不是**免费模型限流**——换 `deepseek/deepseek-chat` 试试；
2. 检查网络和代理（OpenRouter 需要能访问）；
3. 任务有 10~15 秒超时，超时会提示「翻译超时」，不会永远转。

### Q2：提示「还没填 OpenRouter API Key」

- 新版是**新包名**，旧版填的 Key 不会继承，需要重新填；
- 填完必须点 **「保存设置」**，看到「已保存」才算写入。

### Q3：点了「翻译输入框」没反应

- 微信等 App 的输入框**不向无障碍暴露**，读不到内容（这是微信的限制，没有合法办法绕过）；
- X、Telegram、浏览器等标准输入框正常；
- 如果连 Toast 都没有，说明无障碍服务断了，去设置里关掉再打开。

### Q4：无障碍用着用着失效了

- 你是不是把 Syncra 从最近任务里划掉了？划掉 = force-stop，会禁用无障碍；
- 解决方法：重新打开无障碍开关；
- 建议在最近任务里给 Syncra 加锁（常驻后台）。

### Q5：译文只翻了前面十几个字

- 旧版本的 bug，v1.1 已修；
- 如果还遇到，用 **「翻译输入框」** 手动整段翻一次；
- 或打标点符号把句子隔开。

### Q6：翻译内容常驻屏幕、清不掉

- v1.1 已修（关闭自动翻译时会取消进行中的任务）；
- 如果仍遇到：长按悬浮球，或面板里关掉再打开自动翻译。

### Q7：输入框里的字被翻译后「吞掉」了

- 翻译写在输入法还在组合的时候会把后面的字吞掉；
- v1.1 已加防护（写回前比对内容），但仍建议**打完停顿一下**再让它翻；
- 大段内容用**手动整段翻译**最稳。

### Q8：译文语义割裂、前后不连贯

> 作者原话：**「如果出现翻译割裂的问题，可以通过打标点符号进行语句隔离，或者进行手动翻译。」**

具体做法：

- 一句话之间加 `。` `！` `？` 或换行，让它按句翻译；
- 或用 **「翻译输入框」** 手动整段翻。

### Q9：某些 App 完全不翻译

- 部分 App（Flutter、游戏、自绘界面）不把文字暴露给无障碍，读不到；
- 微信的输入框就是典型例子；
- 这时只能用**选中翻译**或换支持的 App。

### Q10：怎么彻底重来

- 主界面 **「清除翻译缓存」**：清掉本地翻译记录；
- 卸载重装会清掉所有设置（包括 Key）。

## 12. 隐私、安全性及 API Key 保管注意事项

### 数据流向

- **API Key**：只存在手机本地；
- **翻译内容**：会发送给你配置的 OpenRouter，由模型翻译；
- **其他**：没有统计、没有广告、没有埋点；
- **缓存**：翻译结果存在本地 `filesDir/translation_cache.json`。

> 作者原话：**「你的一切数据只在本地和大模型之间互传，担心我泄露隐私不如担心模型（笑）。」**

### API Key 保管

- 不要截图分享带 Key 的界面；
- 不要把 Key 提交到任何公开仓库；
- 如果怀疑泄露，去 OpenRouter 后台**删除旧 Key 并重新生成**；
- Key 有额度限制的话，被盗用会消耗你的余额。

### 为什么必须开无障碍

Android 不允许一个 App 读取另一个 App 的界面，也不允许写进别的 App 的输入框。能同时做到这两件事的官方通道**只有无障碍服务**。

Syncra 只用它来：

1. 读取当前屏幕上的文字；
2. 读取并替换输入框里的文字。

它**不会**自动点按钮、跳转页面，也不会在后台收集数据。

## 13. 当前版本的已知限制

- **微信输入框读不到**：微信把输入框标成了不可访问，无解；
- **X 的部分页面不支持选中翻译**：X 的时间线长按是它自己的菜单，不是系统文本选择；
- **部分 App 不暴露文本**：Flutter、游戏、自绘界面无法读屏；
- **免费模型不稳定**：限流会导致翻译失败或变慢；
- **单元测试**：本仓库的单元测试在部分 JVM 环境下跑不起来（环境问题，不影响 APK 使用）；
- **Release 签名**：v1.0 起已换成正式签名（`CN=Syncra`），但正式上架 Google Play 前还需要你自行确认签名保管。

## 14. 作者手写经验（原话整理）

以下是作者反复强调、实测有效的经验，直接照做能少踩很多坑：

1. **大段输入**：先关掉自动翻译，打完再手动点「翻译输入框」。
2. **翻译卡住或报错**：优先换付费模型（DeepSeek 之类的很便宜，一句话的 token 费用接近于零）。
3. **常驻后台**：软件需要常驻后台，一旦从最近任务清理，下次使用要重新打开无障碍模式。**建议在最近任务里锁定。**
4. **2 秒延迟**：翻译有约两秒的防抖延迟，是正常现象。
5. **开源可自证**：App 已在 GitHub 开源，不放心可以让 AI 读源码，再自己打包安装。
6. **数据流向**：你的一切数据只在本地和大模型之间互传，担心作者泄露隐私不如担心模型。
7. **翻译割裂**：通过打标点符号做语句隔离，或者直接手动翻译。

## 15. 界面设置（主界面底部）

| 设置 | 说明 |
|---|---|
| **颜色主题** | 跟随系统 / 浅色 / 深色，选中**即时生效**，不用重启 |
| **输入后延迟** | 滑块 1~5 秒，控制输入框停多久自动翻译，默认 2 秒 |
| **悬浮球大小** | 小 / 中 / 大 |
| **清除翻译缓存** | 清掉本地翻译记录；**不影响 API Key 和其他设置** |

> 注意：v1.2 修掉了「选中翻译卡片反复弹出」——根因是任何设置变化都会让 DataStore 重新发射，旧代码顺手把上次选中的文本又翻了一遍。
