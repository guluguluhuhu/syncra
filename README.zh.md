# BubbleTranslate 双向翻译版（v0.2 · 纯 API 版）

> 基于 [BubbleTranslate](https://github.com/vipinthakur25/bubble-translate)（Apache-2.0，作者 Vipin）改造。
> 原版内置 ML Kit 离线模型（安装包 89MB）；这一版**把模型全部去掉，改走 OpenRouter API**，安装包 **2.2MB**。

## 双向怎么工作

| 方向 | 操作 | 结果 |
|---|---|---|
| **收**（看对方消息） | 长按选中一段文字 → 点蓝色圆点 | 外文翻成中文；中文翻成「对方语言」 |
| **发**（你的发言） | 输入框打好中文 → 点蓝色圆点 | 翻成对方语言并写回输入框，你自己点发送 |

方向自动判断：文本里中文占多数 → 目标是「对方语言」（默认英文）；否则目标是中文。

### X（推特）里没法选中文字怎么办

X 的长按会弹自己的菜单，不会触发 Android 的「文本选中」事件，所以「选中 → 悬浮球」在 X 里用不了。
解决方式是**读屏翻译**：点悬浮球时，无障碍服务直接遍历当前界面的节点树，把屏幕下方最近的几段文字读出来翻成中文，弹一个「原文 → 译文」列表。

用法：让最新消息显示在屏幕中下部 → 点悬浮球（不要长按）→ 每条外文消息下方会出现中文译文。
如果输入框里有字，点悬浮球会优先翻译输入框（那是发送侧）；想读屏就先把输入框清空。

### 逐条贴合与本地缓存

- **逐条**：屏幕上每条外文消息单独翻译，译文画在对应气泡正下方（透明覆盖层，点击会穿透，不影响 X 操作）。
- **持久化**：翻译结果存在 `filesDir/translation_cache.json`，键是原文。同一句只翻一次。
- **不重复调用**：再次点悬浮球时，已翻译过的直接读本地缓存，只把新出现的句子发给 API。
- 切换 App 时译文层自动清空，不会留在别的界面上。

## 安装与配置（4 步）

1. 安装 `dist/BubbleTranslate-API版-v0.2.apk`（Android 10 以上）。
2. 打开 App，填 **OpenRouter API Key**（`sk-or-v1-...`），点「保存设置」。
3. 点「启动悬浮球」，授予「显示在其他应用上层」。
4. 系统设置 → **无障碍** → 已安装的应用 → **BubbleTranslate** → 打开。

## 怎么拿 OpenRouter Key

1. 打开 [openrouter.ai](https://openrouter.ai)，注册账号。
2. 进 **Keys** 页面创建一个 Key，复制。
3. 充一点点钱（翻译一条消息不到一分钱）。
4. ⚠️ 国内访问 openrouter.ai 需要代理，手机上的代理 App 开着（TUN 模式）即可。

默认模型是 `openrouter/free`（OpenRouter 官方免费路由），想换直接在「选择模型」里改。

## 这一版改了什么

- **移除 ML Kit 翻译模型**和 `play-services` 依赖 → 安装包 89MB → 2.2MB
- **新增 OpenRouter 翻译实现**（`OpenRouterTranslationRepository`），只用 `HttpURLConnection` + `org.json`，不引入任何网络库
- **新增设置页**：填 API Key / 选模型 / 保存
- **模型列表自动拉取**（照搬 AIRP 的 `/api/v1/models` 解析）：搜索、免费标识、价格、上下文长度
- **默认免费**：优先 `openrouter/free`（OpenRouter 官方免费路由）；「允许付费模型」开关默认关闭，列表只显示免费模型
- **自动双向**：中文 ↔ 对方语言（英/中/日/韩可选）
- **输入框翻译**：读当前聚焦输入框 → 翻译 → 写回
- 开启 R8 混淆 + 资源收缩，出 release 包

## 模型怎么选

- 打开 App 会后台拉一次模型列表（约 456 个模型，其中免费 19 个）。
- 没选过模型时，自动用 **`openrouter/free`**（官方免费路由，自动分配免费模型）。
- 点「选择模型」可搜索、手动挑；「允许付费模型」开关关闭时，列表只显示免费模型。
- 免费模型标绿并显示「免费」；付费模型显示「入 $x/M · 出 $y/M」。

## 已知限制

- **必须联网**：翻译全部走 OpenRouter，断网就翻不了。
- 输入框如果是特殊实现（不允许外部写入），会弹卡片显示译文，手动复制即可。
- **只翻译，不自动发送**：发送按钮始终由你点，避免被平台判成机器人。
- release 包用的是 debug 签名，自己装机没问题；正式发布要换成自己的 keystore。

## 构建

```bash
# 需要 JDK 17+、Android SDK 36
./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk（约 2.2MB）
```

> 本机构建时 Gradle 发行包走的腾讯云镜像；官方源太慢。
